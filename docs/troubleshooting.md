# 故障排查

## 先复制排查信息

打开搭手中的 **搭手排查卡**，点击 **复制排查信息**，再把以下内容发给测试联系人：

- 当前页面截图；
- 复制的排查信息；
- 你刚才做了什么、卡在哪一步。

排查信息只包含状态、时间、版本、平台和错误类别，不包含授权密码、连接凭据、目录路径、文件内容或 ChatGPT 对话。

## Mac 提示“Apple 无法验证”

这发生在应用还没通过 Apple 付费签名和公证时。按 [Mac 安装与首次打开](mac-install.md) 操作：先点 **完成**，再到 **系统设置 → 隐私与安全性 → 仍要打开**。

不要关闭系统整体安全检查，也不要执行网上来源不明的绕过命令。

## 一直显示“正在连接”

1. 先等待 30 秒；
2. 如果变成 **正在恢复连接**，搭手会有限次数地自动重试；
3. 如果变成 **需要重新启动**，点击页面上的重新启动按钮一次；
4. 仍然失败时复制排查信息。

不要连续快速点击启动，也不要在任务管理器里随意结束不认识的进程。

## 提示“另一套连接正在使用这台电脑”

搭手发现了无法确认归属的另一套连接，因此没有自动结束它。先确认是否同时打开了旧版搭手或另一个安装目录中的 Dashou，然后只保留一个客户端。

如果不确定，不要强行结束进程；把截图和排查信息发给联系人。

## ChatGPT 看不到项目

确认：

1. 搭手显示 **可以使用**；
2. 工作文件夹已经保存；
3. ChatGPT 当前选中了搭手；
4. 当前连接仍显示为已连接。

然后发送：

```text
请重新列出我已经选择的项目。
```

## 授权密码不正确

回到搭手重新点击 **复制授权密码**，不要使用旧截图里的密码，再回到当前授权页面粘贴。

## 升级后仍显示旧版本

1. 从菜单栏或系统托盘选择 **退出搭手**；
2. 重新运行新安装包；
3. 打开搭手 **设置**，查看唯一的版本号位置；
4. 如果仍是旧版本，把安装包文件名、设置页截图和排查信息发给联系人。

不要通过删除配置来“重置版本”，这样只会增加重新连接的成本。
