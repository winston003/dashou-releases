# 连接 ChatGPT

开始前，先确认搭手已经显示 **可以使用**，并且至少选择了一个工作文件夹。

## 1. 从搭手打开 ChatGPT

在搭手“使用”页点击 **去 ChatGPT 连接**。搭手会打开 ChatGPT 的个人连接页面。

如果没有自动打开，可以手动访问：

[ChatGPT 个人插件页](https://chatgpt.com/plugins?view=personal)

## 2. 如果看不到“创建应用”

打开 ChatGPT：

**设置 → 插件 → 开发者模式**

勾选：

- **开发人员模式**；
- **在开发者模式下强制执行 CSP**。

然后返回个人插件页，点击 **创建应用** 或右上角的 **+**。

## 3. 创建搭手连接

按页面提示填写：

- 名称：**搭手**；
- 描述：**让我在授权的本地项目中工作**；
- 连接方式：**服务器 URL**；
- 地址：使用搭手自动复制的连接地址；
- 身份验证：**OAuth**。

每台电脑的连接地址都不同。不要照抄截图中的地址，也不要把地址发到公开地方。

## 4. 完成授权

ChatGPT 打开搭手授权页面后：

1. 点击 **使用搭手登录**；
2. 回到搭手，点击 **复制授权密码**；
3. 回到授权页面粘贴密码；
4. 点击 **允许连接**。

授权密码只用于你当前的 ChatGPT 连接，不要发给其他人。

## 5. 做一次只读检查

在 ChatGPT 中选中搭手，发送：

```text
请列出我已经选择的项目，并告诉我每个项目所在的文件夹名称。先不要修改任何文件。
```

能列出项目后，再开始真实任务。你也可以在 ChatGPT 网页版、电脑端或手机端继续同一类工作；执行仍发生在安装并运行搭手的这台电脑上。
