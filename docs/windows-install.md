# Windows 安装与升级

## 全新安装

1. 双击测试联系人提供的 Windows 安装包；
2. 按安装向导完成安装；
3. 从开始菜单打开 **搭手 Dashou**；
4. 点击 **开始使用搭手**，等待准备完成，再选择工作文件夹。

搭手已经包含所需运行环境，不需要另外安装 Node.js，也不需要打开命令行配置网络参数。

## 如果 Windows 显示安全提醒

当前测试包可能显示“Windows 已保护你的电脑”或“未知发布者”：

1. 先确认安装包确实来自你的搭手测试联系人；
2. 点击 **更多信息**；
3. 点击 **仍要运行**。

不要关闭 Windows 的整体安全防护，也不要运行来源不明的同名安装包。

## 从旧版本升级

直接运行新安装包覆盖安装即可。正常升级会保留：

- 已有连接；
- 已选择的工作文件夹；
- 开机启动和通知偏好。

不要先手动删除配置目录。安装程序会先关闭旧客户端；完成后重新打开搭手，在 **设置** 中确认版本号。

搭手只允许一个客户端窗口实例。重复双击时应回到已经打开的窗口，不应反复出现黑色命令窗口。

如果升级后一直在“正在连接”和“尚未连接”之间变化，请按 [故障排查](troubleshooting.md) 复制排查信息，不要反复卸载。
