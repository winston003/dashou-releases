# 搭手 Dashou

## 让 ChatGPT 走进你授权的本地项目

搭手是一款桌面工具。它让 ChatGPT 在你选择的工作文件夹中读取项目、修改内容、运行命令和执行测试，把“告诉你怎么做”变成“帮你把事情做完”。

![搭手 Dashou 创始内测](images/dashou-founder-pilot.png)

目前是小范围体验。本 README 只讲用户真正需要做的事；版本说明和已知问题会写在对应的 GitHub Release 中。

## 先说明：安装包怎么收到

首批内测的安装包由客服通过微信直接发送：

- Mac 用户收到对应的 `.dmg` 文件；
- Windows 用户收到对应的安装包；
- 版本号以客服发送的文件名为准；
- 这个 GitHub 仓库主要用于公开说明、版本记录和后续发布归档，不要求首批 Mac 用户从 GitHub 下载 DMG。

不要从聊天群、网盘或其他网站下载来路不明的安装包。不要把自己的连接地址、授权密码或申请信息发到公开地方。

## 你需要准备什么

- 一台 Mac 或 Windows 电脑；
- 一个可以使用自定义应用/连接的 ChatGPT 账号；
- 一个你愿意授权给 ChatGPT 使用的工作文件夹。

你不需要安装 Node.js，不需要打开终端，也不需要填写服务器地址、Tunnel Token 或其他网络参数。

## Mac 安装

客服通过微信发送 `.dmg` 文件后：

1. 双击打开 DMG；
2. 把 **Dashou** 拖到 **Applications（应用程序）**；
3. 打开“应用程序”文件夹；
4. 对 **Dashou** 点右键，选择 **打开**；
5. macOS 再询问一次时，点击 **打开**。

![macOS 安装窗口](images/00-macos-install-window.jpg)

免费内测包暂时没有 Apple 官方签名和公证，所以第一次打开可能出现“Apple 无法验证 Dashou”的提示。这是 macOS 的正常保护，不是搭手服务故障。只需要按上面的“右键 → 打开”确认一次；不要关闭 Mac 的整体安全检查，也不需要输入终端命令。

如果 Mac 用户不知道该下载哪个版本，直接把 Mac 型号或芯片截图发给客服，由客服发送正确的 DMG。

## Windows 安装

客服通过微信发送 Windows 安装包后，双击运行并按安装向导完成安装，然后打开 **搭手 Dashou**。Windows 版本不需要另外安装运行环境。

## 第一次使用搭手

打开搭手后，只需要按页面提示完成：

1. 点击 **开始使用搭手**；
2. 等待页面显示“已经收到 → 正在准备 → 准备完成”；
3. 点击 **选择工作文件夹**，可以一次选择多个文件夹；
4. 点击 **开始使用**；
5. 点击 **去 ChatGPT 连接**。

搭手会自动准备这台电脑的连接、复制连接地址并打开 ChatGPT。用户不需要填写任何网络信息。

## 把搭手添加到 ChatGPT

如果搭手已经自动打开 ChatGPT 的添加页面，直接继续。如果没有，可以打开 ChatGPT 的个人插件页：

[打开 ChatGPT 个人插件页](https://chatgpt.com/plugins?view=personal)

在页面中：

1. 点击 **创建应用** 或右上角的 **+**；
2. 名称填写：**搭手**；
3. 描述可以填写：**让我在授权的本地项目中工作**；
4. 连接方式选择 **服务器 URL**；
5. 把搭手自动复制的地址粘贴进去；
6. 身份验证选择 **OAuth**；
7. 勾选页面要求的确认项；
8. 点击 **创建**。

不要照抄任何截图里的地址。每台电脑的地址都不同，只使用搭手自动复制的地址。

### 如果看不到“创建应用”

打开 ChatGPT：

**设置 → 插件 → 开发者模式**

在开发者模式中勾选：

- **开发人员模式**；
- **在开发者模式下强制执行 CSP**。

然后回到[个人插件页](https://chatgpt.com/plugins?view=personal)，再点击 **创建应用**。如果你使用的是工作区账号，也可能需要工作区管理员从 **工作区设置 → 应用 → 创建** 进入。

## 完成授权

创建应用后，ChatGPT 会打开搭手连接页面：

1. 点击 **使用搭手登录**；
2. 回到搭手，点击 **复制授权密码**；
3. 回到 ChatGPT，把密码粘贴到连接页面；
4. 点击 **允许连接**。

授权密码只属于这台电脑和你的 ChatGPT 连接。不要把它发给任何人，也不要发到聊天、Issue 或公开页面。

## 第一次在聊天中使用

回到 ChatGPT 聊天，确认已经选中 **搭手**。第一次建议先发送一个只读任务：

```text
请列出我已经选择的项目，并告诉我每个项目所在的文件夹名称。先不要修改任何文件。
```

确认连接正常后，可以尝试：

```text
请阅读这个项目，告诉我它是做什么的，以及从哪里开始运行。
```

```text
请修复这个项目的测试问题，修改前先告诉我计划，完成后运行测试并汇报结果。
```

搭手连接的是你的 ChatGPT 账号，因此之后可以从 ChatGPT 网页版、电脑端或手机端继续对话。不同设备看到的界面可能不同，但使用的仍是你在搭手里授权的工作文件夹。

## 你始终做主

- 只有你选择的工作文件夹会作为项目提供给 ChatGPT；
- 你可以一次选择多个文件夹，也可以随时添加或移除；
- 搭手不会主动浏览你的电脑；
- 修改文件或运行命令前，ChatGPT 可能会要求确认，请先看清楚它准备做什么；
- 建议第一次使用专门的测试项目，不要直接授权包含密码、身份证件或其他敏感资料的目录。

文件读取和修改只针对你选择的文件夹。运行项目命令时，搭手使用当前电脑账户的权限，因此它不是操作系统级沙箱。

## 关闭和重新打开

关闭搭手窗口不会停止服务：

- Mac：搭手会收起到顶部菜单栏，点击菜单栏图标可以重新打开；
- Windows：关闭窗口后可从系统托盘或开始菜单重新打开；
- 真正停止搭手：从菜单栏或系统托盘选择 **退出搭手**。

## 常见问题

### 点击“开始使用搭手”后没有反应

先等待页面显示状态。如果仍然没有变化，点击搭手页面上的 **复制排查信息**，把复制的内容和截图发给客服。不要发送连接密码、完整日志或账户文件。

### ChatGPT 看不到我的项目

请确认：

1. 搭手已经显示“准备完成”；
2. 已选择正确的一个或多个工作文件夹；
3. ChatGPT 当前选中了搭手；
4. 连接仍然显示为已连接。

然后发送：

```text
请重新列出我已经选择的项目。
```

### 连接密码不正确

回到搭手重新点击 **复制授权密码**，不要使用旧截图或旧密码，再回到当前 ChatGPT 连接页面粘贴。

### 我想更换本地文件夹

在搭手的“使用”页面选择 **重新选择文件夹**，添加或移除文件夹，再回到 ChatGPT 发送：

```text
请重新列出我已经选择的项目。
```

### 我想更新搭手

首批内测用户直接联系发送安装包的客服。客服会发送新的 DMG 或 Windows 安装包，并说明本次改了什么。不要自行删除搭手的配置和授权状态，除非客服明确要求。

## 联系方式

如果遇到问题，请把以下信息发给发送安装包的微信联系人：

- 电脑系统：Mac Apple Silicon、Mac Intel 或 Windows；
- 搭手设置页显示的版本号；
- 页面截图；
- **复制排查信息**的内容。

不要发送连接密码、Token、本地文件内容或完整日志。

感谢你参加搭手的首批体验。真正用过一个真实任务后，反馈哪里省事、哪里卡住，比一句“不错”更有帮助。
