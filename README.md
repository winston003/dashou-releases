# 搭手 Dashou

让 ChatGPT 使用你亲自选择的本地项目。

搭手会把连接、授权和网络准备好。你只需要：

1. 下载并安装搭手；
2. 点击“加入试用”；
3. 选择一个或多个文件夹；
4. 按下面的图片把搭手添加到 ChatGPT。

整个过程不需要安装 Node.js、cloudflared，也不需要填写 Tunnel Token、公网地址或管理员密码。

> 这是小范围内测版本。你选择哪些文件夹，决定 ChatGPT 可以使用哪些项目。请只选择你愿意授权的文件夹。

## 一个连接，三种使用方式

搭手连接好以后，只要使用同一个 ChatGPT 账号，就可以在支持 ChatGPT“聊天”模式的入口继续处理自己的授权工作区：

- 手机 ChatGPT：随时查看项目、阅读文件和继续对话；
- 电脑端 ChatGPT / Codex：适合持续修改、检查和运行项目任务；
- 网页 ChatGPT：适合完整查看工具调用、项目结果和工作过程。

不论从哪一个入口开始，搭手连接的都是你在客户端亲自选择的本地文件夹。先在聊天中选择 **搭手**，再告诉 ChatGPT 你想做什么。

## 下载

请打开最新 Release 页面：

<https://github.com/winston003/dashou-releases/releases/latest>

根据你的电脑选择：

- **Mac Apple Silicon**：M1、M2、M3、M4；
- **Mac Intel**：Intel 处理器的 Mac；
- **Windows**：Windows 安装包。

不要从其他网站下载，也不要把连接地址、授权密码或 Tunnel Token 发给别人。

## macOS 安装

当前免费内测包还没有 Apple Developer ID 签名和公证。第一次打开时，macOS 可能会提示“无法验证开发者”。这不是搭手服务故障。

1. 双击下载的 `.dmg` 文件；
2. 把 **Dashou** 拖到 **Applications（应用程序）**；
3. 打开“应用程序”文件夹；
4. 对 Dashou 点右键，选择 **打开**；
5. macOS 再询问一次时，点击 **打开**。

![macOS 安装窗口](images/00-macos-install-window.jpg)

只需要这样确认一次。之后通常可以直接打开搭手。

如果仍然打不开，请把提示窗口截图发给客服。不要关闭 Mac 的整体安全检查，也不需要打开终端输入命令。

## Windows 安装

双击 Windows 安装包，按安装向导完成安装，然后打开 **搭手 Dashou**。Windows 版本不需要安装额外的运行环境。

## 第一步：在搭手里准备这台电脑

打开搭手后，按顺序操作：

1. 点击 **加入试用**；
2. 等待页面显示准备进度；
3. 准备完成后，点击 **添加文件夹**；
4. 选择一个或多个工作文件夹；
5. 点击 **开始使用**。

搭手会自动准备这台电脑的连接。你不需要输入网络地址、连接码或 Cloudflare 信息。

完成后点击 **去 ChatGPT 连接**。搭手会自动复制这台电脑专属的连接地址，并打开 ChatGPT 页面。

> 截图里的 `device-...warmbyte.studio/mcp` 只是示例。每台电脑的地址都不同，请使用搭手自动复制的地址。

## 第二步：打开 ChatGPT 开发者模式

如果你已经能看到“创建应用”，可以直接跳到下一节。

如果看不到：

1. 打开 ChatGPT；
2. 进入 **设置**；
3. 点击 **插件**；
4. 点击 **开发者模式**。

![进入 ChatGPT 插件设置](images/01-developer-mode-settings.png)

在开发者模式页面打开下面两个开关，然后返回 ChatGPT 的个人插件页面：

![打开 ChatGPT 开发者模式](images/02-developer-mode-switch.png)

直接入口：<https://chatgpt.com/plugins?view=personal>

如果你使用的是工作区账号，可能需要工作区管理员在 **工作区设置 → 应用 → 创建** 中完成这一步。

## 第三步：新建搭手连接

在 ChatGPT 的插件页面：

1. 选择 **个人**；
2. 点击右上角的 **+**；
3. 打开“新插件”窗口。

![点击加号新建插件](images/03-create-app.png)

填写以下内容：

- **名称**：搭手；
- **描述**：让 ChatGPT 使用我授权的本地项目；
- **连接**：选择 **服务器 URL**；
- **服务器 URL**：粘贴搭手自动复制的地址；
- **身份验证**：选择 **OAuth**；
- 勾选“我了解并希望继续”；
- 点击 **创建**。

![填写搭手连接地址](images/04-paste-url.png)

不要手动修改地址，不要把截图中的地址照抄到自己的连接里。

## 第四步：完成搭手授权

创建后，ChatGPT 会显示搭手连接页面。点击：

**使用搭手登录**

![使用搭手登录](images/05-use-dashou-login.png)

随后会打开搭手授权页面。

此时回到搭手窗口，点击 **复制授权密码**；回到浏览器，把密码粘贴到“连接密码”输入框，然后点击 **允许连接**。

![复制授权密码并允许连接](images/06-copy-password-allow.png)

这是这台电脑的连接密码，只在你自己的 ChatGPT 授权页面使用。不要把它发到聊天、Issue 或公开页面。

## 第五步：检查连接权限

连接完成后，在 ChatGPT 中打开：

**设置 → 插件 → 搭手**

可以在这里查看搭手连接和权限。根据你的需要选择权限：

- 只想查看项目：保留较少权限；
- 想让 ChatGPT 新增或修改文件：开启对应的写入权限；
- 想让 ChatGPT 运行项目命令：确认你了解命令会使用当前电脑账户权限后，再开启对应权限。

![查看搭手权限](images/07-plugin-permissions.png)

搭手只会把你在客户端选择的文件夹提供给 ChatGPT。每次让 ChatGPT 修改文件或运行命令前，仍建议先看清楚它准备做什么。

## 第六步：在聊天中使用搭手

回到 ChatGPT 的插件页面，确认“搭手”已经出现在“我创建的”列表中：

![确认搭手已添加](images/08-plugin-list.png)

然后进入 **聊天**，不要停留在“工作”页面。打开消息输入框下方的插件入口，选择 **搭手**：

![在聊天页面选择搭手](images/09-chat-mode.png)

确认输入框附近出现搭手图标后，就可以开始说你的任务：

![搭手已在聊天中启用](images/10-select-dashou.png)

第一次使用建议先做一个只读任务，例如：

```text
请列出我已经授权的项目，并告诉我每个项目所在的文件夹名称。先不要修改任何文件。
```

确认连接正常后，再进行具体工作，例如：

```text
请检查这个项目的 README，告诉我最适合先改进的地方，先不要修改文件。
```

## 关闭和重新打开搭手

关闭窗口不会停止搭手。它会收起到 macOS 顶部菜单栏，连接会继续运行。

- 想重新打开：点击顶部菜单栏的搭手图标；
- 想真正停止：点击顶部菜单栏的搭手图标，选择 **退出搭手**。

Windows 用户关闭窗口后，也可以从开始菜单重新打开搭手。

## 常见问题

### macOS 提示“无法验证 Dashou”

这是免费内测包的正常提示。请在“应用程序”中对 Dashou 点右键，选择“打开”，再点击一次“打开”。不要关闭 Mac 的整体安全检查。

### 找不到“创建应用”

先打开 ChatGPT **设置 → 插件 → 开发者模式**。如果仍然没有，可能是账号类型或工作区策略暂未开放自定义连接，请联系工作区管理员。

### 点击“加入试用”后没有变化

先等待页面显示结果，再重新打开搭手查看状态。如果仍然没有反应，点击页面上的 **复制排查信息**，把这段排查信息发给客服。不要发送连接密码、完整日志、`application.json` 或 `auth.json`。

### ChatGPT 看不到我的项目

回到搭手确认：

1. 试用已经准备完成；
2. 已经选择了正确的一个或多个文件夹；
3. ChatGPT 中已经选中了搭手；
4. 连接仍然显示为已连接。

可以先发送：

```text
请列出我已经授权的项目。
```

### 连接密码不正确

回到搭手重新点击 **复制授权密码**，不要使用旧截图或旧密码。然后回到当前授权页面重新粘贴。

### 我想更换本地目录

在搭手中打开文件夹设置，添加或移除文件夹，再回到 ChatGPT 发送：

```text
请重新列出我已经授权的项目。
```

没有选择的文件夹不会作为项目提供给搭手。

## 隐私和安全

- 只有你选择的文件夹会作为项目提供给搭手；
- 搭手不会要求你把本地文件上传到客服；
- 不要把连接地址、授权密码、Tunnel Token 或管理员信息发到公开地方；
- ChatGPT 可能会在执行修改或命令前请求确认，请认真查看确认内容；
- 如果你不确定，先让 ChatGPT“只读检查，不要修改”。

## 更新

搭手会在客户端中检查新版本。安装包和更新文件只从本仓库的 GitHub Release 获取：

<https://github.com/winston003/dashou-releases/releases/latest>

每个版本的 Release 页面会写明最近改了什么、适用的平台和已知限制。更新时不要删除搭手的设置和授权状态，除非客服明确要求这样做。
