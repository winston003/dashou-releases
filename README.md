# 搭手 Dashou

## ChatGPT 会聊天，搭手让它真正干活

搭手让 ChatGPT 连接你的本地电脑。完成授权后，ChatGPT 可以在你选择的文件夹里读取项目、修改代码、运行命令和完成测试。

你不需要在 ChatGPT 和电脑之间反复复制粘贴，也不需要先学会命令行。你只要说清楚想做什么，搭手就会把结果带回聊天中。

目前是小范围体验。请只选择你愿意让 ChatGPT 使用的工作文件夹。

**你只需要准备：**

- 一台 Mac 或 Windows 电脑；
- 一个 ChatGPT 账号；
- 一个你愿意授权的工作文件夹。

**你不需要准备：**

- Node.js 或其他运行环境；
- 终端命令；
- 网络、服务器或其他技术设置。

## 开始使用，只需要三步

### 第一步：安装搭手，选择工作文件夹

1. 从[最新版本页面](https://github.com/winston003/dashou-releases/releases/latest)下载适合你电脑的安装包；
2. 安装并打开 **搭手 Dashou**；
3. 点击 **加入试用**；
4. 点击 **添加文件夹**，选择一个或多个工作文件夹；
5. 点击 **开始使用**；
6. 点击 **去 ChatGPT 连接**。

搭手会自动准备连接，并打开 ChatGPT 页面。你不需要填写地址或其他技术信息。

**完成标志：**搭手页面显示已经准备好，ChatGPT 页面已经打开。

#### macOS 第一次打开

如果 macOS 提示“无法验证开发者”：

1. 打开“应用程序”文件夹；
2. 对 **Dashou** 点右键，选择 **打开**；
3. 再点击一次 **打开**。

![macOS 安装窗口](images/00-macos-install-window.jpg)

只需要确认一次。不要关闭 Mac 的整体安全检查，也不需要打开终端。

#### Windows 安装

双击 Windows 安装包，按安装向导完成安装，然后打开 **搭手 Dashou**。

### 第二步：把搭手添加到 ChatGPT

如果 ChatGPT 已经显示“创建应用”，直接继续。如果没有看到：

1. 打开 ChatGPT **设置**；
2. 点击 **插件**；
3. 打开 **开发者模式**。

![进入 ChatGPT 插件设置](images/01-developer-mode-settings.png)

开发者模式的入口：[打开 ChatGPT 插件设置](https://chatgpt.com/plugins?view=personal)

在 ChatGPT 的插件页面：

1. 选择 **个人**；
2. 点击右上角的 **+**；
3. 打开“新插件”窗口。

![点击加号新建应用](images/03-create-app.png)

按页面填写：

- **名称**：搭手；
- **描述**：让我在授权的本地项目中工作；
- **连接方式**：服务器 URL；
- **服务器 URL**：粘贴搭手自动复制的地址；
- **身份验证**：OAuth；
- 勾选“我了解并希望继续”；
- 点击 **创建**。

![填写搭手连接地址](images/04-paste-url.png)

“OAuth”只是页面上的一个选项，照图选择即可，不需要理解这个词。不要照抄截图里的示例地址；每台电脑的地址都不同。

创建后，点击 **使用搭手登录**：

![使用搭手登录](images/05-use-dashou-login.png)

回到搭手窗口，点击 **复制授权密码**；再回到浏览器，把密码粘贴到“连接密码”输入框，点击 **允许连接**。

![复制授权密码并允许连接](images/06-copy-password-allow.png)

这是这台电脑的连接密码，只在你自己的 ChatGPT 页面使用。不要把它发给别人，也不要发到聊天或公开页面。

**完成标志：**ChatGPT 的应用列表里出现 **搭手**。

### 第三步：在聊天中选择搭手

先确认“搭手”出现在“我创建的”列表中：

![确认搭手已添加](images/08-plugin-list.png)

然后进入 **聊天**，打开输入框下方的插件入口，选择 **搭手**：

![在聊天页面选择搭手](images/09-chat-mode.png)

确认输入框附近出现搭手图标后，发送第一条消息：

```text
请列出我已经选择的项目，并告诉我每个项目所在的文件夹名称。先不要修改任何文件。
```

![搭手已在聊天中启用](images/10-select-dashou.png)

**完成标志：**ChatGPT 能列出你刚才选择的项目。

## 一次连接，三种使用方式

同一个 ChatGPT 账号，可以从不同入口继续处理搭手连接的工作文件夹：

- **手机**：随时查看项目、阅读文件和继续对话；
- **网页**：适合完整查看工作过程和任务结果；
- **电脑端**：适合持续修改、检查和运行项目任务。

![手机、网页和电脑端都可以使用搭手](images/dashou-three-screens.png)

## 你可以让搭手做什么

你可以直接用自然语言提出任务：

```text
请阅读这个项目，告诉我它是做什么的，以及从哪里开始运行。
```

```text
请修复登录页面的这个问题，修改前先告诉我你的计划，完成后运行测试。
```

```text
请运行项目测试。如果失败，告诉我失败原因，先不要修改文件。
```

建议先从“阅读、说明、检查”开始，熟悉后再让搭手修改文件或运行命令。

## 多个文件夹和隐私

- 你可以一次选择多个工作文件夹；
- 只有你选择的文件夹会作为项目提供给 ChatGPT；
- 你可以随时添加或移除文件夹；
- 搭手不会要求你把本地文件发送给客服；
- ChatGPT 修改文件或运行命令前，可能会先请求确认，请看清楚它准备做什么。

你始终可以做主。不确定时，先让 ChatGPT **只读检查，不要修改**。

## 常见问题

### 找不到“创建应用”

打开 ChatGPT **设置 → 插件 → 开发者模式**。如果仍然没有，可能是账号类型或工作区设置暂未开放自定义连接，请联系工作区管理员。

### 点击“加入试用”后没有变化

先等待页面显示结果，再重新打开搭手查看状态。如果仍然没有反应，点击页面上的 **复制排查信息**，把排查信息发给客服。不要发送连接密码、完整日志或账户文件。

### ChatGPT 看不到我的项目

请依次确认：

1. 搭手已经准备完成；
2. 已选择正确的一个或多个文件夹；
3. ChatGPT 中已经选中了搭手；
4. 连接仍然显示为已连接。

然后发送：

```text
请重新列出我已经选择的项目。
```

### 连接密码不正确

回到搭手重新点击 **复制授权密码**，不要使用旧截图或旧密码，再回到当前连接页面重新粘贴。

### 我想更换本地目录

在搭手中打开文件夹设置，添加或移除文件夹，再回到 ChatGPT 重新列出项目。没有选择的文件夹不会作为项目提供给搭手。

## 关闭和更新

关闭窗口不会停止搭手。macOS 上它会收起到顶部菜单栏；点击搭手图标可以重新打开，选择 **退出搭手** 才会真正停止。

搭手会在客户端中检查新版本。安装包和更新文件只从本仓库的[最新版本页面](https://github.com/winston003/dashou-releases/releases/latest)获取。

可以把本 README 交给你信任的 AI 助手，并让它：

3. 每一步都等你看到“完成标志”后再继续；
4. 不索要你的连接密码、账号密码或本地文件。
